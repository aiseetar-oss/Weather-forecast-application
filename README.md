# Weather Forecast Application 🌤️

## About the Project
A responsive weather application that provides current weather information and a 7-day forecast for different cities.

## Features
- Search weather by city name
- Current temperature
- Weather description and icons
- Humidity and wind speed
- 7-day weather forecast
- Refresh weather information
- Responsive design

## Technologies Used
- HTML
- CSS
- JavaScript
- Open-Meteo API

## How to Run
1. Open the project in VS Code.
2. Open index.html using Live Server.

## Weather API
Weather data provided by Open-Meteo.
https://open-meteo.com/
